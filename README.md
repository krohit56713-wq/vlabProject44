## 📌 Project Overview & Resource Citations

1. **Task Details & Design Standards:**  
   - Source: Data Alcott Systems Internship Portal.
   - Design guidelines implemented: Navy Blue (`#1A3C5E`), White (`#FFFFFF`), Red Accent (`#E63946`).
2. **Icons:** FontAwesome CDN library (`cdnjs.cloudflare.com`).
3. **Images:** Open-source automotive images from Unsplash (`unsplash.com`).
4. **Data Management:** Pure JavaScript Arrays and `localStorage` (No Database Required).

---

## 🚀 Features

- **Home Page:** Banner, Categories grid, Featured products.
- **Product Listing:** Filter by Category and Vehicle type.
- **Cart & Wishlist:** Real-time quantity adjustment, total calculation, local data persistence.
- **Checkout & Account:** Simulated order submission and history tracking.
